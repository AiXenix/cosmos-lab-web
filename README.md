# AiXenix Cosmos Lab

[Play in your browser](https://aixenix.github.io/cosmos-lab-web/)

Published browser build of the AiXenix space sandbox, with a Russian/English
interface and handbook, WebAssembly N-body physics, and a navigable galaxy map.
This repository contains the compiled client and public catalogue assets.

Galaxies are static models. Navigation flights are animations; N-body physics
runs in the local systems you enter. Observed and procedural data are labelled.
This is an early browser build; the full original feature plan is not complete.
